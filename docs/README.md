# tailwind-merge-java

A utility to efficiently merge [Tailwind CSS](https://tailwindcss.com) classes in Java without style conflicts.

- Supports Tailwind CSS v4 up to v4.3 (the same target as the reference project)
- Thread-safe LRU caching
- Compatible with Java 8 or newer, no runtime dependencies
