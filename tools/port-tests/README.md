# port-tests

Generates the Java version of the C# behavior tests that are plain lists of `[InlineData]` cases.

Most files in `docs/references/tailwind-merge-dotnet/tests/` are theories like

```csharp
[Theory]
[InlineData( "inset-x-1 inset-1", "inset-1" )]
public void Merge_ClassGroups_MergesCorrectly( string classLists, string expected )
{
    var actual = new TwMerge().Merge( classLists );
    Assert.Equal( expected, actual );
}
```

Retyping hundreds of those by hand invites typos, and the porting rule is that cases and expected values
must be the reference ones. `gen-tests.js` reads the attributes and writes a JUnit 5 class
(`@ParameterizedTest` + `@MethodSource`) with exactly the same strings.

It is a development tool only. It is not part of the published library and Maven does not build it.

## Usage

Needs only Node.js (no dependencies). From the repository root:

```bash
node tools/port-tests/gen-tests.js ClassGroups ColorsClasses
node tools/port-tests/gen-tests.js --tests <dir> --out <dir> ClassGroups
```

`Name` is the C# file name without the `Tests.cs` suffix (`ClassGroupsTests.cs` → `ClassGroups`) and the
output is `<Name>Test.java`. Defaults: `--tests docs/references/tailwind-merge-dotnet/tests`,
`--out src/test/java/com/github/ddxailab/tailwindmerge`. Existing files with the same name are overwritten,
so never run it over a test that was edited by hand.

For every file it prints the number of converted methods and cases. Compare the cases with
`grep -c InlineData <file>.cs`; they must match.

## What it converts

- One theory → one provider method (`xxxCases()`) and one test method; `Merge_Foo_MergesCorrectly` becomes
  `mergeFooMergesCorrectly`.
- String concatenation (`"a " + "b"`), C# escapes and the `//` comments between the attributes (kept).
- `null` as expected value is written as `""`: the Java API returns an empty string, never `null`
  (see the *Decisions* table in `docs/CHECKLIST.md`).

## What it does not convert

- A method with the signature `(string x, string expected)` whose body is not the standard
  `new TwMerge().Merge( arg )` + `Assert.Equal( expected, actual )` makes the script fail with exit code 1.
- Methods with any other signature (`[Fact]`, tests that use `Extend`/`Override`, the cache, mocks...) are
  skipped without a message. Port them by hand and check the method count against the C# file.

## When to use it

- Porting a new test file from the reference.
- Updating to a newer reference version: regenerate into a temporary directory (`--out`) and diff against
  `src/test/java/...` to see exactly which cases were added or changed upstream.

Used in Step 9 of the conversion: eight files, 325 cases, regenerated byte for byte with this script.
